\# Personal Finance Tracker

A simple command-line application to track your income and expenses.



\## Features

\- Add income and expense transactions.

\- View a financial summary.

\- See transaction history with dates.

\- Categorize and analyze expenses.

\- Delete transactions.

\- Supports European (1.250,50) and US (1,250.50) number formats.



\## Installation

```bash

git clone https://github.com/Electusys/finance-tracker.git

cd finance-tracker

python finance\_tracker.py

```



\## Usage

Run the application:

```bash

python finance\_tracker.py

```



\## Requirements

\- Python 3.6+
